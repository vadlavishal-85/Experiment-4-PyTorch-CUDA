# Experiment 4 - PyTorch CUDA

## Aim
To create and manage a deep learning project repository using Git and GitHub, configure PyTorch with CUDA, and perform GPU-based tensor computations.

## Project Structure
- dataset/: Stores datasets
- models/: Stores trained models
- notebooks/: Stores Jupyter notebooks
- results/: Stores output results
- train.py: Training script
- inference.py: Inference script
- requirements.txt: Project dependencies

## Technologies Used
- Python
- PyTorch
- CUDA
- Git and GitHub
